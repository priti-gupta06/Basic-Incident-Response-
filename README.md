# Basic-Incident-Response-
study the basic stages of incident response and create a response checklist


## Overview
This project explains the basic stages of cybersecurity incident response and provides a practical incident response checklist.
It was completed as part of Task 25 of the Cyber Security Internship Track at Veda Technology.

## Objective
- Understand incident response fundamentals.
- Learn how to detect and analyze security incidents.
- Understand containment, eradication, and recovery.
- Prepare a checklist for handling cybersecurity incidents.
- Identify lessons learned after an incident.

## Stages of Incident Response

### 1. Preparation
Prepare response procedures, security tools, backups, logs, and team contact details.

### 2. Detection and Analysis
Identify suspicious activity, examine alerts, determine the scope, and preserve relevant evidence.

### 3. Containment
Limit the spread and impact of the incident by isolating affected systems or accounts when appropriate.

### 4. Eradication
Remove malware, unauthorized access, and the underlying security weakness.

### 5. Recovery
Restore systems from trusted sources, verify their security, and monitor for recurring activity.

### 6. Lessons Learned
Document the incident, review the response, and improve security procedures.

## Incident Response Checklist
-  Identify and record the incident.
-  Record the time and source of the alert.
-  Identify affected systems and accounts.
-  assess the incident's severity.
-  Preserve relevant evidence and logs.
-  Contain affected systems when appropriate.
-  Remove the root cause.
-  Restore and verify affected systems.
-  Monitor for recurring suspicious activity.
-  Document the incident and lessons learned.
